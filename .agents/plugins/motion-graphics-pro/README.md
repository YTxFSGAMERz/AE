# Motion Graphics & After Effects Pro (`motion-graphics-pro`)

A complete, production-grade Antigravity plugin bundling deep After Effects automation, native C/C++ plugin engineering, CEP/UXP extension development, Remotion React motion graphics, professional VFX compositing, continuous editing learning, and senior motion designer interview coaching.

---

## Bundled Skills

| Skill | Trigger / Scope | Description |
| :--- | :--- | :--- |
| **`after-effects-scripting`** | After Effects JSX / ExtendScript automation | Automate compositions, layers, properties, keyframe easing, match names, and render queues via procedural scripts. |
| **`after-effects-sdk-plugin`** | C/C++ native plugin engineering | Develop Effect and AEGP plugins with SmartFX 32-bpc floating-point color, parameters, and GPU shaders (CUDA, OpenCL, Metal). |
| **`cep-ae-extension`** | HTML5 / Node.js extension panels & UXP | Build, debug (`.debug`), and package (`ZXPSignCMD`) interactive CEP panels and migrate to modern UXP plugins. |
| **`remotion-motion-kit`** | React + Remotion programmatic video | Create kinetic text, stat cards, screen frames, sound-scored motion graphics, and batch ProRes 4444 renders. |
| **`after-effects-motion-design`** | AE animation, VFX & technical artistry | Master easing curves, 2.5D parallax camera rigs, Keylight green screen compositing, particle simulations, and expression rigs. |
| **`motion-design-interview-prep`** | Interview preparation & mock coaching | 30 curated technical, STAR behavioral, and HR questions with model answers, rubrics, and interactive mock interview mode. |
| **`motion-editor-learning`** | Adaptive memory & editing mastery | Continuously observes and learns your timing preferences, typography, color palettes, and stylistic rules as you work. |

---

## Universal Project Rules
- Automatic undo groups around all ExtendScript routines (`app.beginUndoGroup`).
- Official Adobe Match Names enforced for all effects, shapes, and properties.
- ProRes 4444 with straight alpha channels for transparent video exports.
- S-curve and asymmetrical velocity easing curves for organic motion.
- Automatic recording of user stylistic preferences into persistent memory.
