## 1. The Wafer — recommended

A stranger can repeat it: the factory did not run out of sand. The same wafer now feeds an AI chip, and that chip takes about three times the wafer for the same amount of memory.

- **Device / form:** the object is the explanation. An endless zoom.
- **What you see and feel:** A price tag tears. The camera falls through the new number into a silicon wafer, then into one tall server that is eating the slices a desktop kit used to get. You feel the kit in your hands get thinner without anyone touching it.
- **First two seconds:** Frame 0 is a white retail sticker reading `$80` on a 32GB DDR5 box. The sticker rips on the cut. `$449` is already there, full frame, before the first second ends.
- **Beats:** hook (the sticker rips) → tension (the same box, three price eras, the chip underneath going $8.70 → $48) → reveal (one wafer, named) → proof (the wafer divides; about three slices leave for an HBM stack, one slice stays for a desktop kit; Crucial’s consumer shelf goes dark) → payoff (the zoom climbs back out to his desk, the 32GB box still closed, the game unlaunched) → claim (“Your RAM did not get worse. The wafer left.”) → end card (YTxFSGAMERz).
- **Look:** A lit electronics counter, then the wafer’s own mirror. Ground `#e7e2d6` paper on the counter, ink `#14181c`, accent only on the price and the wafer edge `#ff4d1c`. Type: a heavy condensed grotesque for the price, a plain sans for the labels. One material: the wafer, a reflective disc with a grid of dies, no glow.
- **Sound:** A dry tick-tock bed near 100 bpm, almost no low end, so a phone speaker still hears it. Silence for the rip. One impact when `$449` lands. The bed opens when the wafer appears. A single soft tick as each die leaves the disc. No voice.

## 2. The Quiet Desk

A stranger remembers the moment before Play: the PC is already busy, and RAM is the expensive thing it is spending.

- **Device / form:** a moment in someone’s day. One frame that rebuilds and never leaves the monitor.
- **What you see and feel:** Night, one monitor, a game launcher waiting on Play. The launcher peels back into Task Manager. Rows of processes stack into a column that eats a marked 5 GB on a 16 GB stick. You feel late for a match you have not started.
- **First two seconds:** Frame 0 is the Play button, in focus, with a small clock reading 01:14. A process counter in the corner is already climbing past 200 before anyone clicks.
- **Beats:** hook (Play is waiting, the counter is not) → tension (rows keep arriving; a 5 GB block fills on a 16 GB stick while the game is still closed) → reveal (“This is idle.”) → proof (his published clean-Windows range: 210–240 processes, 4.8–5.5 GB idle, drawn as one stick, labelled as his measurement) → payoff (the rows collapse; the stick shows what is left for the game) → claim (“The match starts on the RAM Windows already spent.”) → end card (YTxFSGAMERz).
- **Look:** A real desk seen only as the monitor. Ground is the panel, `#0e1412`. Text `#e7f2ea`. Accent `#c6f54e` used once, on the gigabytes the game does not get. Type: a square technical sans, tabular numbers. One material: the LCD, scanlines from the panel itself, no added grain.
- **Sound:** Room tone and a faint coil whine under a slow pulse. A soft key tick for each process row. The pulse cuts out when the rows collapse. No voice.

## 3. The Second Key — the bold one

A stranger learns that the lock on their browser is already doing a second job, for a computer that is not here yet.

- **Device / form:** the object is the explanation. Match cuts: one circle holds while the world changes.
- **What you see and feel:** A brass keyhole. It becomes the lock icon in Chrome. It becomes a lattice of points, a second key turning inside the same circle. Ordinary, then strange, then ordinary again. The lock was never only the lock you knew.
- **First two seconds:** Frame 0 is an extreme close-up of a brass keyhole, a key already half in. The bow of the key is stamped `2026`. It turns.
- **Beats:** hook (the key turns) → tension (the same circle is now a login form; a second, invisible key is drawn beside it and labelled as the one a future machine would try) → reveal (“Two keys. One lock.”) → proof (the circle becomes the Chrome lock; a short line that this key exchange, ML-KEM, has been the default since late 2024) → payoff (both keys sit in the one circle; the future key does not fit the old notch) → claim (“Your browser already locked the door twice.”) → end card (YTxFSGAMERz).
- **Look:** A workbench, warm metal, not a diagram void. Ground `#1c140e`, brass `#d7a15a`, paper label `#f3ead7`, ink `#1a120c`. Accent `#d7a15a` only on the second key. Type: a sturdy serif for the claim, a small sans for the label. One material: machined brass, a real key, no particles.
- **Sound:** A solo upright-bass pulse, slow. One key-turn scrape at the start, one metallic click when the second key fails the old notch. The bass stops on the claim. No voice.
